# Download
1. Download the .blend from the latest release on the [Releases](https://github.com/goribby/IndianaJones-MultiRig/releases) page.

2. Open the file.

# Instructions

## Changing skins and camera settings
- Click the "Properties" bone, the one shaped like a cog. <br>
- From that, press N on your keyboard to pull up the N panel, then go to the Item tab, then go to Properties. <br>
- There, you can drag the Skin menu to select which skin you want, from 1 to 4. <br>
- Checking/unchecking the Hat option turns on/off the hat, along with its bone collection. <br>
- The "Camera Track" property controls how much the camera bone will use the camera track bone (crosshair) for camera transformations. If you'd like to just use the camera bone instead, just set that to 0.<br>

## IK Fingers
- All fingertip bones have IK to make posing easier, that means you can just move the tip and the other finger bones will follow it, instead of rotating each bone individually. </br>
- If you'd like to disable this, click the respective hand bone, press N to pull up the N panel, go to Item, Properties, and set "IK Fingers L or R" to 0. </br>
